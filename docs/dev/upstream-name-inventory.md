# Upstream name inventory (Phase 0)

Scope of this snapshot: the stock `releng` profile as installed by
`archiso 92-1`, plus downloaded packages `mkinitcpio-archiso 73-1`,
`filesystem 2025.10.12-1`, `arch-install-scripts 32-1`,
`archinstall 4.5-1` and `calamares 3:3.4.3-1` (blackarch proxy for the
Calamares version we plan to build; contents are assumed close to an
upstream build and are marked unverified for that reason).

Method: `rg -i -c 'archlinux|arch linux|archiso|ARCH_|archinstall|arch-chroot'`
over each tree. Counts are per file, matching lines only.

## Build-host facts recorded during discovery

- Host is pacman-based (CachyOS), which satisfies the build requirement,
  but its enabled third-party repos (cachyos, blackarch, multilib) must
  never leak into OmidenOS builds: the build profile `pacman.conf` lists
  only `[core]`, `[extra]`, and a local `file://` `[omidenos]`.
- `mkarchiso` (archiso 92-1) exists on the host and stays in the build
  environment only (S4); the ISO carries our `omidenos-initcpio` hooks.
